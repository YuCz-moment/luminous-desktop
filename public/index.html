操作提示
  • 素材
    • 点「＋素材」添加：网页 / 图片 / 文字 / 音频 / 视频；也可以直接把文件拖进画布，或 Ctrl+V 粘贴截图 / 一段文字
    • 网页卡：自动抓取 logo、标题、简介、封面，可手动修改；双击简介直接编辑；拖一张图片到卡片上可替换封面
    • 图片卡：纯图显示，点击浮现工具栏（AI 分析 / 裁剪）；右下角可拖拽缩放
    • 文字卡：双击输入，字号随卡片大小自动缩放；音频 / 视频支持本地大文件，存入 IndexedDB，刷新不丢
    • 文档卡（桌面版）：直接拖入 Word / Excel / PPT / PDF，双击即可用 WPS / Office 打开；卡片只存路径，不占画布空间
    • 顶栏「筛选」可只看某一类素材
  • 卡片
    • 左键拖动移动；Alt+左键拖出 = 复制一份
    • Ctrl+左键逐张加选 / 取消，Ctrl+左键拖空白处框选；选中后可批量移动、复制、删除、整组缩放
    • 右键卡片：删除 / 复制到画外（切换到其他画布后可粘贴）
    • 拖卡片右侧小圆点到另一张卡建立连线；悬停连线出现删除按钮，双击连线也可删除
  • 画布
    • 左键拖空白处平移；滚轮缩放（5%～300%）
    • 右下角小地图：开关按钮显示 / 隐藏，点击或拖动可定位；缩放率实时显示，点击百分比恢复 100%
    • 「适配画布」「重置视图」一键归位
    • ⋯ 菜单：画布背景（预设 / 自定义颜色 / 图片 / 纹理）、新建 / 重命名 / 删除画布；顶部下拉切换画布，双击名字重命名
  • 快捷键
    • Ctrl+Z 撤销 · Ctrl+Y 重做 · Ctrl+S 保存 · Ctrl+O 导入 · Ctrl+E 导出 · Ctrl+N 新建画布 · Ctrl+V 粘贴
  • AI
    • ⋯ → AI 模型设置：填接口地址 / API Key / 模型名，可「测试连接」；分析时图片会发送到你填写的接口
    • 图片卡点「AI 分析」生成设计关键词卡片；⋯ → AI 看画布可一键总结整张画布
  • 数据
    • 画布与素材全部保存在本机浏览器；导出为 JSON（自动打包图片 / 视频 / 音频），发给别人后可直接导入打开
